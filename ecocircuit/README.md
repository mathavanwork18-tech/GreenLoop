# EcoCircuit ♻️⚡

**Reuse Electronics. Reduce E-Waste.**

A modern, responsive cross-platform Flutter application for circular electronic waste management, refurbishment, trade-in, and certified recycling.

---

## 🚀 Key Features

- **📱 Dynamic Home Dashboard**:
  - Live carbon offset counters and circular economy metrics.
  - Interactive categories: Smartphones, Laptops, Audio, Components, Batteries, and Cables.
  - Curated deals on verified refurbished devices.

- **🛒 Smart Marketplace & Refurbished Store**:
  - Filter by condition (Brand New, Refurbished - Like New, Good, For Parts).
  - High-res image carousels, detailed hardware specs, and battery health reporting.
  - Secure cart and carbon-neutral checkout workflow.

- **🚚 Carbon-Neutral Checkout**:
  - Flexible delivery speeds (Standard eco-delivery / Express courier).
  - Multiple payment demo gateways (UPI, Credit/Debit Cards, Cash on Delivery).

- **📦 Sell & Trade-in Flow**:
  - Quick listing generator for used electronics.
  - Functional condition grading and automated AI valuation estimates.

- **🗺️ Recycling & Drop-off Centers**:
  - Interactive directory of certified state-authorized e-waste collection points.
  - Operating hours, contact info, and accepted item types.

- **🎨 Adaptive Theming**:
  - Tailored Emerald Green design language.
  - Full Light Mode and Dark Charcoal Mode support with persistent state.

## 🛠️ Tech Stack

- **Framework**: Flutter 3.x / Dart 3.x
- **Design System**: Material Design 3 (Emerald Green Palette)
- **State Management**: `ChangeNotifier` / `InheritedNotifier` Provider pattern

## 💻 Getting Started

### 1. Prerequisites
Ensure you have the Flutter SDK installed on your system:
```bash
flutter --version
```

### 2. Install Dependencies
```bash
cd ecocircuit
flutter pub get
```

### 3. Run Application
```bash
# Run on connected emulator or device
flutter run

# Run on Chrome for Web Preview
flutter run -d chrome
```

### 4. Run Code Analysis
```bash
flutter analyze
```
